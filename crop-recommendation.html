PROJECT 02 / APPLIED AI

Fuzzy Crop Recommendation

A decision-support web application using fuzzy logic to recommend crops from environmental conditions.

PythonFlaskscikit-fuzzyPandas

The challenge

Rainfall, temperature and humidity are not always best described by rigid thresholds. Fuzzy membership functions can represent low, medium and high conditions.

What I implemented

Data preparation

Processed historical agricultural and weather inputs.

Fuzzy inference

Mamdani inference, with 27 rules per crop across five crops.

Web interface

Connected the recommendation logic to a Flask application.

System flow

Rainfall, temperature, humidity → Fuzzy membership → Rule inference → Crop recommendation

Conceptual architecture, not a live inference demo.
